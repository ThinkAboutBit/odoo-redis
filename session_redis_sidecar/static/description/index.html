The Problem with Traditional Redis Sessions

Standard Odoo Redis session modules connect to a single Redis endpoint. Every page request requires a network round-trip to read the session (~1ms). At scale, this becomes a bottleneck.

Why This Module is Different

🚀 Dual Connection Architecture

Writes to Redis Master, reads from local sidecar replica. Best of both worlds.

⚡ Ultra-Fast Localhost Reads

Session reads via localhost (~0.1ms) instead of network (~1ms). 10x improvement.

☸️ Kubernetes-Native Design

Built for the sidecar container pattern. Each pod has its own Redis replica.

🔄 Automatic Fallback

If local replica misses (replication lag), automatically reads from Master.

🔀 No Sticky Sessions

Works with any load balancer algorithm. Round-robin, least connections, random.

💪 Fault Tolerant

Pod failure doesn't lose sessions. Session data persists on Redis Master.

Quick Start

1. Install Dependencies

pip install redis

2. Configure odoo.conf

[options]
server_wide_modules = base,web,session_redis_sidecar

3. Set Environment Variables

# Kubernetes Sidecar Mode
export REDIS_MASTER_HOST=redis-master.redis.svc.cluster.local
export REDIS_LOCAL_HOST=localhost

# Single Redis Mode (development)
export REDIS_MASTER_HOST=redis
export REDIS_LOCAL_HOST=redis

Configuration Reference

Variable Default Description
